# Scorer สร้างนักกีฬาและเจ้าหน้าที่ทีมจาก Match settings

Scorer สร้างข้อมูลนักกีฬาและเจ้าหน้าที่ทีมลง Master data ได้จากแมตช์ที่ตนมีสิทธิ์เข้าถึงตามการมอบหมายรายการแข่งขันของระบบเดิม ข้อมูลพร้อมใช้งานทันทีหลังบันทึก ไม่ต้องรอผู้ดูแลอนุมัติ ฟีเจอร์นี้ไม่เพิ่มสิทธิ์สร้างหรือแก้ไขผู้ตัดสิน

## นักกีฬา

1. เปิด Match settings แล้วเลือกแท็บ Teams
2. ค้นหาใน “เพิ่มนักกีฬาจากรายชื่อทีม” ก่อน ถ้าพบให้เลือกบุคคลเดิม
3. หากไม่มี ให้กด “สร้างนักกีฬาใหม่และเพิ่มเข้าแมตช์” ใต้ทีมที่ต้องการ
4. กรอกชื่อ นามสกุล หมายเลขเสื้อเริ่มต้น เพศ และวันเกิดสำหรับรายการที่กำหนดรุ่นอายุ เลือกตำแหน่งการเล่นเริ่มต้นได้
5. กด “เพิ่มในรายการรอบันทึก” แล้วตรวจรายชื่อ หมายเลข และบทบาท Libero/กัปตันในแมตช์
6. กด “บันทึกข้อมูลหลักและเพิ่มเข้าแมตช์” หรือ “บันทึกข้อมูลหลักและปิด” เพื่อสร้างข้อมูลหลักและบันทึกการตั้งค่าแมตช์ทั้งหมดพร้อมกัน

ฐานข้อมูลเดิมกำหนดให้ข้อมูลนักกีฬามีหมายเลขเสื้อด้วย จึงใช้หมายเลขที่กรอกเป็นค่าเริ่มต้นในทะเบียนทีม ส่วนหมายเลขและบทบาทที่แก้ในแมตช์ภายหลังคงเป็นข้อมูลเฉพาะแมตช์ ไม่แก้ข้อมูลหลักโดยอัตโนมัติ บทบาทกัปตันและ Libero ของนักกีฬาใหม่ไม่ได้ถูกนำไปตั้งเป็นบทบาทหลักของทีม

## เจ้าหน้าที่ทีม

ในแท็บ Team staff สามารถเลือกเจ้าหน้าที่จากข้อมูลหลักของทีม หรือกด “สร้างเจ้าหน้าที่ทีมใหม่และเพิ่มเข้าแมตช์” ได้ รองรับผู้จัดการทีม ผู้ฝึกสอนหลัก ผู้ช่วยผู้ฝึกสอน แพทย์ และนักกายภาพ/เทรนเนอร์

ปุ่ม “เพิ่มเจ้าหน้าที่เฉพาะแมตช์นี้” ยังคงใช้สำหรับรายชื่อที่ต้องการบันทึกเฉพาะแมตช์ ส่วนปุ่มสร้างข้อมูลหลักจะเพิ่มลงทะเบียนเจ้าหน้าที่ทีมและเชื่อมกับรายการแข่งขันเมื่อบันทึกสำเร็จ

## เงื่อนไข

- สร้างได้เฉพาะสองทีมที่ผูกกับแมตช์จริง โดยใช้รหัสทีมจากฐานข้อมูลฝั่ง server
- ต้องออนไลน์ แมตช์ยังไม่เริ่ม Live ไม่ถูกล็อกผลตรวจรับ และไม่มีการยืมสิทธิ์บันทึก Offline อยู่
- หากเป็นแมตช์รายการแข่งขัน ทีมต้องมีทะเบียนอนุมัติตรงรุ่น และรายชื่อยังไม่ถูกล็อก นักกีฬาต้องผ่านเงื่อนไขเพศ รุ่นอายุ และจำนวนสูงสุดเดิม
- ไม่สร้างชื่อบุคคลซ้ำในทีม และไม่ใช้หมายเลขนักกีฬาที่มีผู้เล่นใช้อยู่แล้ว หากเป็นคนละคนแต่ชื่อเหมือนกัน ให้ผู้ดูแลตรวจสอบก่อน
- การสร้างข้อมูลหลัก การผูกทะเบียน การบันทึกแมตช์ และประวัติผู้สร้างอยู่ใน transaction เดียวกัน หากส่วนใดผิดพลาดจะไม่เหลือข้อมูลหลักค้าง
- การยกเลิกก่อนกดบันทึกไม่สร้าง Master data การนำบุคคลออกจากแมตช์หลังบันทึกไม่ลบ Master data ที่สร้างแล้ว
- แมตช์ส่วนตัวสร้างข้อมูลหลักได้เมื่อเป็นเจ้าของและผูกทีมจริงเท่านั้น ไม่เพิ่มบุคคลเข้ารายการอื่นโดยอัตโนมัติ

## การตรวจสอบ

- Backend: `npm.cmd run test:match-master-data`
- Browser ใน client: `npm.cmd run test:match-master-data:browser`
- Frontend: `npm.cmd run lint` และ `npm.cmd run build`

Browser test ใช้ข้อมูลจำลองใน PGlite และ scope checks ของฐานจำลอง ไม่เชื่อมต่อ Supabase จริง ไม่ทดสอบ native advisory-lock serialization ซึ่งมีชุด native tests แยกอยู่แล้ว

ใช้ตารางเดิม `players`, `team_staff`, `team_entry_players`, `team_entry_staff`, `matches` และ `audit_logs` ไม่ต้องเพิ่ม migration ต้อง deploy โค้ด backend และ frontend เพื่อใช้งานบนเว็บไซต์ออนไลน์
