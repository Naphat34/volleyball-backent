# ภาษาไทยและอังกฤษ

การเลือกภาษาใช้ค่าเดียวกันทั้งแอป: `THA` หรือ `ENG` เก็บใน `localStorage.language` และซิงค์เมื่อเปลี่ยนจากแท็บอื่น ค่าเดิม เช่น `TH`, `THAI`, `EN` และ `English` ถูกแปลงเป็นค่ามาตรฐาน ส่วนเอกสารที่สร้างใน React root แยกจากแอปจะอ่านภาษาปัจจุบันที่เก็บไว้

ข้อความหน้าผู้ดูแล ทีม หน้าสาธารณะ Scorer และ VIMS ใช้ `useUiTranslation` ส่วน `useScorerTranslation` และ `useVisTranslation` เรียกตัวแปลเดียวกัน คำแปลรวมจากชุดเดิมและ `applicationCopy.js` / `additionalCopy.js` เพื่อไม่ให้ข้อความเดียวกันมีภาษาไม่ตรงกันในหน้าต่างย่อย

ชื่อบุคคลและทีมใช้ `useDisplayNames` โดยเลือกชื่อที่ลงทะเบียนไว้ ไม่มีการแปลหรือถอดเสียงชื่อเฉพาะอัตโนมัติ หากไม่มีชื่อภาษาที่เลือกจะใช้ชื่อเดิม และไม่ผสมชื่อกับนามสกุลคนละภาษา ไม่เปลี่ยนรหัสนักกีฬา หมายเลขเสื้อ กัปตัน หรือไลน์อัปที่บันทึกไว้

หน้าต่างแก้ไขนักกีฬาและแมตช์สร้างเองรองรับการกรอกชื่อสองภาษา API ไลน์อัปส่งชื่อสองภาษากลับมาด้วย การคัดลอกแมตช์และไฟล์ข้อมูลเก็บช่องชื่อเหล่านี้ไว้ เอกสารที่สร้างใหม่เลือกชื่อตามภาษา ส่วนไฟล์ PDF แม่แบบทางการยังมีหัวข้อที่พิมพ์ไว้ในแม่แบบเดิม

ข้อความที่แทรกชื่อหรือข้อมูลใช้ placeholder เช่น `ui('{0} Coach', [teamName])` ห้ามแปลชื่อด้วยการแทนที่คำบางส่วน ข้อความที่ผู้ใช้กรอกเอง รหัสกติกา เช่น C/L1/L2 และชื่อผลิตภัณฑ์คงเดิม

ตรวจสอบจาก `client`:

```powershell
npm.cmd run test:i18n
npm.cmd run lint
npm.cmd run build
```

`test:i18n` ตรวจตัวเลือกภาษา ชื่อที่แสดง และเรนเดอร์ส่วนประกอบจริงในภาษาไทย อังกฤษ และค่าเก่า `TH` รวมกรณีหน้าต่างจัดตัวที่เคยแสดงข้อความภาษาอังกฤษในโหมดไทย

ตรวจ API แบบไม่เชื่อมฐานข้อมูลจริงจาก `backend`:

```powershell
node --test tests/scorerBilingualNames.test.js tests/manualScorer.test.js tests/bilingualNames.test.js tests/matchSettings.test.js
```
