# Scorer Console บน iPad

- หน้าจอกว้างต่ำกว่า 1536px ใช้แผงหลักหนึ่งคอลัมน์ แทนแถบข้างสามแผง
- เปิดรายชื่อและคำสั่งของแต่ละทีมจากปุ่มใต้คะแนน และให้คะแนนได้จากปุ่มสองทีมใต้แผงคะแนน ปุ่มให้คะแนนเปิดเฉพาะขณะเล่นคะแนน (RALLY)
- ตั้งค่า ดูบันทึกเหตุการณ์ และย้อนรายการได้จากแถบด้านบน
- สนามรักษาสัดส่วนเดิมและย่อในแนวนอนเพื่อเหลือพื้นที่ให้ปุ่มควบคุม หากพื้นที่ไม่พอสามารถเลื่อนแผงหลักลงได้
- ปุ่มควบคุมหลักมีความสูงอย่างน้อย 44px หน้าต่างย่อยจำกัดความสูงตามพื้นที่หน้าจอ และช่องกรอกใช้ตัวอักษรอย่างน้อย 16px เพื่อหลีกเลี่ยงการซูมเมื่อโฟกัสบน iOS
- หน้าต่างจัดตัวบนจอไม่เกิน 1100px แสดงสนามทั้งสองทีมด้านบน แล้วแสดงรายชื่อด้านล่าง

ตรวจบน Safari/iPad จริงทั้งแนวตั้งและแนวนอน โดยเฉพาะขนาด 768×1024, 820×1180, 1024×768, 1180×820 และ 1366×1024 รวมถึงโหมดแบ่งหน้าจอ:

1. ตรวจชื่อทีมไทย/อังกฤษที่ยาว คะแนน สนาม และการเลื่อนถึงปุ่มควบคุม
2. ทดสอบให้คะแนนหนึ่งครั้งและตรวจว่าปุ่มปิดใช้งานเมื่อเข้าสู่สถานะรอเสิร์ฟ
3. สลับฝั่งสนาม แล้วเปิดรายชื่อทั้งสองทีม ตรวจว่ารายชื่อและคำสั่งตรงทีม
4. เปิดจัดตัว ตั้งค่า เปลี่ยนตัว และชาลเลนจ์ ตรวจว่าปิดหน้าต่างและกดยืนยันได้
5. หมุนเครื่อง เปิด/ปิดแถบ Safari และโฟกัสช่องกรอก ตรวจว่าปุ่มไม่ถูกตัดออก

ชุดทดสอบส่วน Scorer: `node --test src/utils/scorer/*.test.js` จากโฟลเดอร์ `client` ส่วนการทดสอบสัมผัสและพื้นที่หน้าจอจริงต้องตรวจบนอุปกรณ์เพิ่มเติม
