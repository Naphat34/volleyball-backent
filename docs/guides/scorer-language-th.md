# ภาษาใน Scorer Console

- เลือก **THAI** หรือ **EN** ที่แถบด้านบน ข้างปุ่มเต็มหน้าจอ
- เปลี่ยนภาษาได้ทันทีโดยไม่ต้องโหลดหน้าใหม่ ระบบจำภาษาผ่านตัวเลือกภาษาเดิมของแอป
- ครอบคลุมแผงคะแนน รายชื่อและการจัดตัว เสี่ยงเหรียญ เปลี่ยนตัว ลิเบอโร เวลานอก ชาลเลนจ์ บทลงโทษ การปรับคะแนน ลายเซ็น คำขอจากเจ้าหน้าที่ และประวัติการแข่งขัน
- วันที่แสดงเป็น พ.ศ. ในภาษาไทย และ ค.ศ. ในภาษาอังกฤษ รวมถึงเวลาในประวัติรูปแบบเดิม
- ชื่อทีมบนแผงคะแนนใช้ชื่อไทยหรืออังกฤษที่ลงทะเบียนไว้ตามภาษา หากไม่มีชื่อในภาษานั้นจะแสดงชื่อเดิม และยังเลือกชื่อได้หลังรีเฟรชหรือเปิดข้อมูลที่แคชไว้
- ชื่อนักกีฬาเลือกจาก `first_name_th`, `last_name_th`, `first_name_en`, `last_name_en` ตามภาษา หากไม่มีชื่อในภาษานั้นจะใช้ชื่อเดิม สามารถกรอกชื่อทั้งสองภาษาได้จากหน้าต่างแก้ไขนักกีฬา และช่องชื่อสองภาษาในแมตช์สร้างเอง
- ข้อความที่กรอกเองและข้อมูลเหตุการณ์ที่บันทึกไว้คงเดิม การแปลประวัติทำเฉพาะตอนแสดงผล ข้อความผิดพลาดจากเซิร์ฟเวอร์ที่ยังไม่มีคำแปลจะแสดงข้อความต้นฉบับ
- รหัสกติกา เช่น C, L1, L2 และ IR ใช้เหมือนกันทั้งสองภาษา

คำแปลอยู่ที่ `client/src/utils/scorer/scorerUiTranslations.js` และใช้ผ่าน `useScorerTranslation` ในส่วนประกอบ Scorer ส่วนข้อความที่มีชื่อหรือค่าจากการแข่งขันให้ใช้ placeholder เช่น `st('{0} won the toss.', [teamName])` เพื่อไม่แปลข้อมูลที่แทรกเข้าไป

ตรวจสอบจากโฟลเดอร์ `client`:

```powershell
node --test src/utils/scorer/*.test.js
npm.cmd run lint
npm.cmd run build
npm.cmd run test:i18n
```
