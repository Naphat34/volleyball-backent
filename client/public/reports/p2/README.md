# P-2 report artwork

These PNGs preserve the logos supplied in the user's reference P-2 PDF.
The report draws new match data; it does not reuse the reference's team names,
player data, scores, or export timestamp.

- `competition-logo.png`: competition artwork, including its original transparent padding.
- `association-logo.png`: association artwork.
- `partners.png`: footer partner artwork.

Replace these assets when using a different competition's branding.
